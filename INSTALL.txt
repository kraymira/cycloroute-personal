1. Открой CycloRoute-Personal.osf через OsmAnd и импортируй всё.
2. В велосипедном профиле: Configure map → Map style → CycloRoutePersonalMVP.
3. Configure map → Толщина велолиний → Текущая / Толще / Максимальная.
   Толщина меняется без повторного импорта; при необходимости прокрути меню вниз.
4. Удерживай + или − на карте → Map magnifier → 25%.
   Затем выставь кнопками карты нужную линейку, например 5 km.

Легенда: My Places → My Favourites → CycloRoute Personal.

Назад: выбери «Текущая». Полный возврат к 1.1 — импортируй
releases/CycloRoute-Personal-1.1.osf из исходников с заменой файлов.

Для своих базовых толщин: измени width в line-widths.json, выполни
python3 release.py и импортируй новый .osf с заменой файлов.

Для просмотра карты BRouter устанавливать не требуется.
Новый переключатель 1.2 проверен правилами рендерера; на телефоне пока не проверен.
