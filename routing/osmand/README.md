# Bicycle infrastructure in OsmAnd Android

This source patch targets OsmAnd commit `a16fabdbd9034388abe044c7a6a1f89237c4c8a0`. It adds bicycle infrastructure to the calculated route preview and to the Route information widget during navigation. The route line uses blue for mapped bicycle facilities and purple for other sections.

The `cycleways-preferred` BRouter profile supplies route points, turn hints and way tags in a single GeoJSON response. The displayed distance is the sum of marked sections, and the percentage uses the full calculated route as its denominator. Separate cycleways, designated shared paths, bicycle streets and designated bike lanes count. Shared traffic and bus lanes are excluded. The preview reports the distance with unknown tags separately. The map and statistics use the current route result, including after a recalculation.

Apply `bicycle-coverage.patch` in the OsmAnd Android source checkout and build a separate APK using the [OsmAnd Android build instructions](https://osmand.net/docs/technical/build-osmand/how-to-compile-the-android-version/). The Nightly build uses package `net.osmand.dev` and can be installed alongside the stock app. Import the CycloRoute map style and configure BRouter offline with the existing `cycleways-preferred` profile in the new app. The standard CycloRoute OSF contains map resources and cannot install the Android source patch.

The parser and coverage calculation were checked on real BRouter responses from Gandia and Oliva, including a route with zero mapped bicycle facilities. The signed ARM64 Nightly debug APK builds successfully. The targeted BRouter checks pass. The full upstream Java suite had one failure in the search localization test, which enumerates resource files using a URL path under a workspace containing spaces. The preview APK build skipped that upstream test task. On a Galaxy S23, the Gandia route showed blue and purple segments and 1.67 km of mapped bikeways (62%) in the preview. The Route information widget showed the metric during simulated navigation. A 1.07 km route in Oliva was calculated with 0% mapped bikeways. Automatic recalculation on a real ride remains unverified.
