# Экспериментальная маршрутизация

Это отдельная часть проекта. Установка основного `.osf` не включает её.

- `cycleways-preferred.brf` предпочитает велоинфраструктуру и допускает разрешённые обычные дороги для соединения сети. Его мягкий коэффициент **не гарантирует** предельный объезд 20% в Android.
- `cycleways-baseline.brf` — контрольный вариант для сравнения длины.
- `cycleways-strict.brf` — прежний строгий прототип, исключающий обычные соединения. При разрыве сети ожидается отсутствие маршрута.
- `BoundedRoute.java` — отдельный компьютерный адаптер двух расчётов: выбирает preferred при совпавших привязках и длине не более 1.20 baseline, иначе baseline. Он не встроен в Android и не доказывает глобальный оптимум графа.

Для профилей нужен BRouter, отдельно скачанные RD5 и подключение внешнего движка в OsmAnd. Инструкция интеграции: https://osmand.net/docs/user/navigation/routing/brouter/ . Данные карты не гарантируют соответствие дорожным знакам и временным ограничениям.

`build_mvp.py` также создаёт дополнительный пакет `dist/mvp/CycloRoute-MVP-Android.osf` с минимальными общими настройками профиля BRouter. Он не входит в основной установочный файл для просмотра карты; после его импорта нужно проверить фактический Navigation type. Минимальный профиль поставки не является экспортом личных настроек телефона.
